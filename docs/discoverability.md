# Discoverability: topics and description

GitHub repository **topics** and the short **description** drive search and
related-repo surfacing. They are repo *settings*, not files, so this document
records the recommended values to apply in repository settings (Settings →
General, and the "About" gear on the repo home page).

Topics and description are derived from the README's actual vocabulary; do not
invent unrelated terms.
